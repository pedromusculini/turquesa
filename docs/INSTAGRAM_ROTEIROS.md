## Norte criativo

### Por que I.A. (e não face cam)

Teste real: vídeo I.A. “ruim” e grátis performou melhor que vídeo com o fundador.  
Daí em diante: **viralizar com I.A.** + **provar o produto com tela honesta** do sistema.

### Regra de ouro — honestidade

| Mentira / exagero (evitar) | Honestidade (fazer) |
|----------------------------|---------------------|
| “App mágico que responde WhatsApp sozinho” | Semi-automático: template + wa.me, toca e envia |
| UI inventada / mock fake do Turquesa | Só screen record real |
| “Substitui o WhatsApp” | Complementa: links, lembretes, CRM |
| Prometer API Meta / robô 24h | Não — produto atual é wa.me + links |

### Dor central (vale pros dois mercados)

Profissional **no meio do atendimento** — mãos ocupadas, não dá pra viver no celular.  
Perde timing de **cliente novo(a)** e de quem **não volta**.

**Descartar:** agenda no papel / caderno / “anotar em 3 lugares”.

### Solução (sempre amarrar)

Autocadastro · autoagendamento · catálogo online · templates WhatsApp · lembretes · CRM (sem retorno / uma visita / aniversário) · financeiro + gráficos · sync Google Calendar.

### Dois “mundos” visuais (mesmo produto)

| Tag | Público | Visual I.A. | Voz TTS | Pronomes no copy |
|-----|---------|-------------|---------|------------------|
| **S** | Salão / manicure / lash | unhas, cílios, cadeira de salão | feminina, dona de salão | ela / cliente / manicure |
| **B** | Barbearia | corte, barba, cadeira de barbeiro | masculina, dono de barbearia | ele / cliente / barbeiro |

Mesma dor, mesma feature, **skin diferente** — o algoritmo entrega pra nichos distintos.

### Mix de publicação (obrigatório)

**A cada 2 vídeos S (salão/manicure/lash), 1 vídeo B (barbeiro).**

```
S → S → B → S → S → B → S → S → B …
```

Não postar 4 salões seguidos. Não postar 2 barbearias seguidas no começo (até ter volume).

R$ 79,90/mês
